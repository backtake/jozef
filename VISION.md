# Vision

Jozef is a personal desktop AI agent — the operational model of JARVIS from Iron Man.

It runs in the background, listens for its wake word, understands speech, reasons
with a configurable LLM, executes tools (PC automation, browser, Gmail, Calendar),
and answers by voice — proactively when needed.

Windows is only the first runtime target. Platform-specific code stays behind
interfaces so macOS, Linux, Android and other clients can follow.
